# Sana Vita — сайт медичного центру

Статична верстка сайту за макетом у Figma: десктоп (1440) і мобільна версія (375), з адаптацією під планшет.

## Сторінки

| Файл | Сторінка |
|---|---|
| `index.html` | Головна |
| `doctor.html` | Сторінка лікаря (шаблон) |
| `prices.html` | Ціни |
| `contacts.html` | Контакти |
| `hemorrhoids.html` | Послуга «Лікування геморою» (шаблон сторінки послуги) |
| `booking.html` | Запис онлайн: лікар → дата й час → контакти → підсумок |

## Структура

- `src/pages/*.html` — вміст сторінок; `src/partials/` — спільні шапка, футер, блок запису.
- `build.ps1` — збирає готові `*.html` у корені з `src/`. **Редагуйте файли в `src/`**, потім запустіть:

  ```powershell
  powershell -ExecutionPolicy Bypass -File build.ps1
  ```
- `styles.css` — усі стилі (токени кольорів з макета, шрифт Montserrat); `script.js` — інтерактив.
- `assets/` — зображення та іконки з макета.

## Що працює

Слайдер на головній (автоперемикання 3 с, пауза, свайп), слайдер послуг, мобільне меню, вибір мови, акордеони прайсу та FAQ, форми запису з маскою телефону й перевіркою полів, онлайн-запис із календарем на поточний місяць (неділя — вихідний) і живим підсумком.

Форми поки не надсилають дані на сервер — лише перевіряють поля й показують підтвердження.
