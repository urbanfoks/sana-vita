# Sana Vita — головна сторінка

Статична верстка головної сторінки медичного центру Sana Vita за макетом у Figma (десктоп 1440, з адаптацією під планшет і мобільний).

- `index.html` — розмітка
- `styles.css` — стилі (токени кольорів з макета, шрифт Montserrat)
- `script.js` — слайдер у Hero (автоперемикання 3 с, пауза), слайдер послуг, мобільне меню, вибір мови, форма запису з маскою телефону
- `assets/` — зображення та іконки з макета

Запуск: просто відкрийте `index.html` у браузері або увімкніть GitHub Pages для гілки `main`.
